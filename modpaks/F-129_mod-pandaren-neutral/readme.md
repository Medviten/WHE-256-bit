# mod-worgoblin-high-elf
## F-129_mod-pandaren-neutral

### Features
- Neutral Pandaren (race 24), an NPC race: not playable, no race mask for players
- Everything F-020 and F-021 have in common: the models, customization, names, voices and totems, the dragon turtle mounts and the racials. They copy or activate it for their own race, so neither can overwrite the other's rows

### Setup
- List this modpak before F-020 and F-021, which need it. It is 256-bit only: the 32-bit version keeps the two modpaks as they were, as an NPC race would cost one of its few race slots
