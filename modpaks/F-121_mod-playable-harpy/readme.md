# mod-worgoblin-high-elf
## F-121_mod-playable-harpy

### Features
- Playable Harpies (Horde), race ID set in config.sql, one body for both genders
    - CoA's model and textures from Ilusixn's CoA 1.9.9 release (CoA race 56), prepared by `tools/models/coa199_race_prep.py`
    - Customization: CoA's own CharSections, hair and facial hair rows for its race 56
    - Home: Tauren (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: BloodElf (voice, emotes and names, copied at build time)
    - Helmet prefix 'Be'
    - Model size and display scale from CoA's CreatureModelData/CreatureDisplayInfo rows
- Generated by `tools/races/coa199_race_modpaks.py` (tentative, for testing)

### Requirements
- Client files from `tools/models/coa199_race_prep.py` (in WHE-common's `patch-A.MPQ`)
- Interface: race button and the HARPY entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`

### Credits
- Model and textures: Project Ascension, in Ilusixn's CoA Custom release. See `CREDITS.md` in Ilusixn's CoA 1.9.9 release, which must ship with them

### Known Issues
- Tentative: not tested in game yet
- No racial mount
- Placeholder race icon
- Barber shop styles have generic names
- Character creation camera is not tuned for the model's size
- One body: both genders use it, with the Kin race's voices

### CoA Custom 1.9 racials
- Active: learned with the racial skill line
- From CoA (Ilusixn's CoA 1.9.9 release, CoA race 56) (Harpy), renumbered; blocks at the end of `[BASE,F-121]_spell.sql`, `_skilllineability.sql` and `_spellicon.sql`
    - Wing Gust: Escape the effects of any immobilization or movement speed reduction effect and become immune to them for $81001d.
    - Screech: Stuns up to $i enemies within $a1 yds for $d.
    - Swift Talons: Increases your dodge chance by $s1%.
    - Keen Eyes: Increases your Stealth detection.
