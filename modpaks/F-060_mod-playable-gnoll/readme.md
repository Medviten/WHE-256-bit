# mod-worgoblin-high-elf
## F-060_mod-playable-gnoll

### Features
- Playable Gnolls (Alliance), race ID set in config.sql
    - Model, textures and customization from Ilusixn's CoA 1.9.9 release (see Look)
    - Home: Human (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Human (voice, emotes and names, copied at build time)
    - Helmet prefix 'Hu'
- Generated by `tools/races/new_race_modpaks.py` (tentative, for testing)

### Requirements
- Custom client with `creatureSkinRaces` containing the race ID: the skin texture is composited whole and armour textures are not drawn on it
- Interface: a race button and the GNOLL entries in `CharacterCreate.lua`, `GlueParent.lua` and `GlueStrings.lua`

### Look
Model, textures and customization from Ilusixn's CoA 1.9.9 release (CoA race 83), put in place by `tools/races/coa199_replace.py`. Author: CoA Custom (Ilusixn); see `CREDITS.md` in the release, which must ship with these files.

### Known Issues
- Tentative: not tested in game yet
- No racial mount
- Placeholder race icon, racial faction name and description
- Barber shop styles have generic names
- Character creation camera is not tuned for the model's size

### CoA Custom 1.9 racials
- Active: learned with the racial skill line
- From CoA race 83 (Gnoll), renumbered; blocks at the end of `[BASE,F-060]_spell.sql`, `_skilllineability.sql` and `_spellicon.sql`
    - Pack Howl: Increases your attack and casting speed by $s1% for $d. Does not stack with other similar cast speed increasing effects.
    - Bone Gnaw: When activated, regenerates $20578s1% of total health every $20578t1 sec for $20578d.  Only works on Humanoid or Undead corpses within $a1 yds.  Any movement, action, or damage taken while Cannibalizing will cancel the effect.
    - Scavenger: Allows the dwarf to sense nearby treasure, making it appear on the minimap.  Lasts $d.
    - Thick Hide: Base Health increased by $s1%.
