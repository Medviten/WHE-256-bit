# mod-worgoblin-high-elf
## F-118_mod-playable-lost-one

### Features
- Playable Lost Ones (Alliance), race ID set in config.sql, one body for both genders
    - CoA's model and textures from Ilusixn's CoA 1.9.9 release (CoA race 125), prepared by `tools/models/coa199_race_prep.py`
    - Customization: the 9/9 skin colours of CoA's appearance catalog (`EsteriaLostOne.bin`); its other options (EsteriaAppearance.dll) are fixed at their first choice
    - Home: Draenei (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Draenei (voice, emotes and names, copied at build time)
    - Helmet prefix 'Gn'
    - Model size and display scale from CoA's CreatureModelData/CreatureDisplayInfo rows
- Generated by `tools/races/coa199_race_modpaks.py` (tentative, for testing)

### Requirements
- Client files from `tools/models/coa199_race_prep.py` (in WHE-common's `patch-A.MPQ`)
- Custom client with `creatureSkinRaces` containing the race ID: the skin texture is composited whole and armour textures are not drawn on it
- Interface: race button and the LOSTONE entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`

### Credits
- Model and textures: the AllRaces v12 pack: Furioz, Corruption, Eunoia, Kalibros (STRHercules). See `CREDITS.md` in Ilusixn's CoA 1.9.9 release, which must ship with them

### Known Issues
- Tentative: not tested in game yet
- No racial mount
- Placeholder race icon
- Barber shop styles have generic names
- Character creation camera is not tuned for the model's size
- CoA's extra appearance options (EsteriaAppearance.dll) are not available
- One body: both genders use it, with the Kin race's voices

### CoA Custom 1.9 racials
- Active: learned with the racial skill line
- From CoA (Ilusixn's CoA 1.9.9 release, v12 racials of CoA race 125) (Lost One), renumbered; blocks at the end of `[BASE,F-118]_spell.sql`, `_skilllineability.sql` and `_spellicon.sql`
    - Lost to the Void: You walked through the dark and came back. Reduces Shadow damage taken by 3%.
    - Spectral Pace: Half your steps are not quite in this world. Increases your movement speed by 3%.
    - Echo of the Light: A remnant of the Light still answers. Spirit increased by 5%.
    - Ghostly Dispersion: Slip half out of the world, reducing all damage you take by 90% for 6 sec. 2 minute cooldown.
