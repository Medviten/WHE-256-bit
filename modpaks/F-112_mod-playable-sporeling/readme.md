# mod-worgoblin-high-elf
## F-112_mod-playable-sporeling

### Features
- Playable Sporelings (Alliance), race ID set in config.sql, one body for both genders
    - CoA's model and textures from Ilusixn's CoA 1.9.9 release (CoA race 111), prepared by `tools/models/coa199_race_prep.py`
    - Customization: the 11/11 skin colours of CoA's appearance catalog (`EsteriaSporeling.bin`); its other options (EsteriaAppearance.dll) are fixed at their first choice
    - Home: Gnome (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Gnome (voice, emotes and names, copied at build time)
    - Helmet prefix 'Gn'
    - Model size and display scale from CoA's CreatureModelData/CreatureDisplayInfo rows
- Generated by `tools/races/coa199_race_modpaks.py` (tentative, for testing)

### Requirements
- Client files from `tools/models/coa199_race_prep.py` (in WHE-common's `patch-A.MPQ`)
- Custom client with `creatureSkinRaces` containing the race ID: the skin texture is composited whole and armour textures are not drawn on it
- Interface: race button and the SPORELING entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`

### Credits
- Model and textures: the AllRaces v12 pack: Furioz, Corruption, Eunoia, Kalibros (STRHercules). See `CREDITS.md` in Ilusixn's CoA 1.9.9 release, which must ship with them

### Known Issues
- Tentative: not tested in game yet
- No racial mount
- Placeholder race icon
- Barber shop styles have generic names
- Character creation camera is not tuned for the model's size
- CoA's extra appearance options (EsteriaAppearance.dll) are not available
- One body: both genders use it, with the Kin race's voices

### CoA Custom 1.9 racials
- Active: learned with the racial skill line
- From CoA (Ilusixn's CoA 1.9.9 release, v12 racials of CoA race 111) (Sporeling), renumbered; blocks at the end of `[BASE,F-112]_spell.sql`, `_skilllineability.sql` and `_spellicon.sql`
    - Spore-Blooded: The cap keeps you dry in any storm. Reduces Nature damage taken by 3%.
    - Quick Spores: Small legs, big stride. Increases your movement speed by 3%.
    - Mycelial Mind: A tiny cap holds a very clever head. Intellect increased by 5%.
    - Spore Burst: Burst your cap in a cloud of spores, dealing Nature damage to all enemies within 10 yards and slowing their attack speed. 1 minute cooldown.
