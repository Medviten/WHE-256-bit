# mod-worgoblin-high-elf
## F-122_mod-playable-illidari-blood-elf

### Features
- Playable Illidari Blood Elves (Horde), race ID set in config.sql
    - CoA's model and textures from Ilusixn's CoA 1.9.9 release (CoA race 60), prepared by `tools/models/coa199_race_prep.py`
    - Customization: CoA's own CharSections, hair and facial hair rows for its race 60
    - Home: BloodElf (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: BloodElf (voice, emotes and names, copied at build time)
    - Helmet prefix 'Be'
    - Model size and display scale from CoA's CreatureModelData/CreatureDisplayInfo rows
- Generated by `tools/races/coa199_race_modpaks.py` (tentative, for testing)

### Requirements
- Client files from `tools/models/coa199_race_prep.py` (in WHE-common's `patch-A.MPQ`)
- Interface: race button and the ILLIDARIBLOODELF entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`

### Credits
- Model and textures: Furioz, Corruption and the Eunoia team. See `CREDITS.md` in Ilusixn's CoA 1.9.9 release, which must ship with them

### Known Issues
- Tentative: not tested in game yet
- No racial mount
- Placeholder race icon
- Barber shop styles have generic names
- Character creation camera is not tuned for the model's size

### CoA Custom 1.9 racials
- Active: learned with the racial skill line
- From CoA race 60 (Illidari Blood Elf), renumbered; blocks at the end of `[BASE,F-122]_spell.sql`, `_skilllineability.sql` and `_spellicon.sql`
    - Spectral Sight: Dramatically increases stealth detection for $d.
    - Fel Rush: Escape the effects of any immobilization or movement speed reduction effect and become immune to them for $81001d.
    - Demon Hunter's Resolve: Duration of Stun effects reduced by an additional $s1%.
    - Felblood: Reduces the damage taken by Shadow spells by $s1%.
