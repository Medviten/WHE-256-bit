# mod-worgoblin-high-elf
## F-108_mod-playable-titan

### Features
- Playable Titans (Alliance), race ID set in config.sql, one body for both genders
    - CoA's model and textures from Ilusixn's CoA 1.9.9 release (CoA race 91), prepared by `tools/models/coa199_race_prep.py`
    - Customization: the 9/9 skin colours of CoA's appearance catalog (`EsteriaTitan.bin`); its other options (EsteriaAppearance.dll) are fixed at their first choice
    - Home: Dwarf (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Human (voice, emotes and names, copied at build time)
    - Helmet prefix 'Gn'
    - Model size and display scale from CoA's CreatureModelData/CreatureDisplayInfo rows
- Generated by `tools/races/coa199_race_modpaks.py` (tentative, for testing)

### Requirements
- Client files from `tools/models/coa199_race_prep.py` (in WHE-common's `patch-A.MPQ`)
- Custom client with `creatureSkinRaces` containing the race ID: the skin texture is composited whole and armour textures are not drawn on it
- Interface: race button and the TITAN entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`

### Credits
- Model and textures: the AllRaces v12 pack: Furioz, Corruption, Eunoia, Kalibros (STRHercules). See `CREDITS.md` in Ilusixn's CoA 1.9.9 release, which must ship with them

### Known Issues
- Tentative: not tested in game yet
- No racial mount
- Placeholder race icon
- Barber shop styles have generic names
- Character creation camera is not tuned for the model's size
- CoA's extra appearance options (EsteriaAppearance.dll) are not available
- One body: CoA's female model for both genders; the other model's textures are in neither the release nor retail

### CoA Custom 1.9 racials
- Active: learned with the racial skill line
- From CoA (Ilusixn's CoA 1.9.9 release, v12 racials of CoA race 91) (Titan), renumbered; blocks at the end of `[BASE,F-108]_spell.sql`, `_skilllineability.sql` and `_spellicon.sql`
    - Keeper's Fortitude: Forged to outlast the ages. Total health increased by 5%.
    - Order Unyielding: The Titans' order shuns the corruption of the Old Gods. Reduces Shadow damage taken by 3%.
    - Titan-forged Might: Your frame was made for towering strength. Strength increased by 5%.
    - Aegis of the Keepers: The Titans' ward closes around you, absorbing damage equal to 100% of your maximum health for 15 sec. 2 minute cooldown.
      (CoA sizes the absorb with the C++ script spell_titan_aegis (titan_aegis.cpp), which WHE does not have: without it the shield absorbs its base amount only)
