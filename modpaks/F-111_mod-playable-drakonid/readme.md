# mod-worgoblin-high-elf
## F-111_mod-playable-drakonid

### Features
- Playable Drakonid (Horde), race ID set in config.sql, one body for both genders
    - CoA's model and textures from Ilusixn's CoA 1.9.9 release (CoA race 98), prepared by `tools/models/coa199_race_prep.py`
    - Customization: the 17/17 skin colours of CoA's appearance catalog (`EsteriaDrakonid.bin`); its other options (EsteriaAppearance.dll) are fixed at their first choice
    - Home: Orc (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Orc (voice, emotes and names, copied at build time)
    - Helmet prefix 'Dk'
    - Model size and display scale from CoA's CreatureModelData/CreatureDisplayInfo rows
- Generated by `tools/races/coa199_race_modpaks.py` (tentative, for testing)

### Requirements
- Client files from `tools/models/coa199_race_prep.py` (in WHE-common's `patch-A.MPQ`)
- Custom client with `creatureSkinRaces` containing the race ID: the skin texture is composited whole and armour textures are not drawn on it
- Interface: race button and the DRAKONID entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`

### Credits
- Model and textures: Kalibros | Lord of Wen (STRHercules), Esteria races. See `CREDITS.md` in Ilusixn's CoA 1.9.9 release, which must ship with them

### Known Issues
- Tentative: not tested in game yet
- No racial abilities yet
- No racial mount
- Placeholder race icon
- Barber shop styles have generic names
- Character creation camera is not tuned for the model's size
- CoA's extra appearance options (EsteriaAppearance.dll) are not available
- The DLL's baked armour (geosets 200xx, drawn with its texture type 14) is hidden
- One body: both genders use it, with the Kin race's voices
