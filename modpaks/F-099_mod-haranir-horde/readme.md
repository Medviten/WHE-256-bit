# mod-worgoblin-high-elf
## F-099_mod-playable-haranir-horde

### Features
- Playable Haranir (Horde), race ID 91 (retail's) set in config.sql
    - Retail model and full Retail customization in the wowdecomp-256-bit client (its `retailRaces` setting, default `37=37,52=52,70=70,86=86,91=91`)
    - Everything else sees the Troll model and customization rows (a client without Retail support shows a troll)
    - Home: Troll (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Night Elf (voice, emotes and names, copied at build time)
    - Helmet prefix 'Ni'
- Generated by `tools/races/haranir_modpaks.py` (tentative, for testing)

### Requirements
- wowdecomp-256-bit client built with `WOWDECOMP_RETAIL_ASSETS=ON`, with the Haranir Retail files (a `pack=` folder from `RetailPackBuild <pack> 86 91`, a local CASC or the Blizzard CDN)
- azerothcore-wotlk-256-bit with the Retail look tables and opcodes (characters keep their full customization)
- Interface: race button and the HORDEHARANIR entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`; `RetailRace_CharacterCreate.lua` for the Retail options

### Known Issues
- Tentative: not tested in game yet
- No racial abilities yet
- No racial mount
- No Haranir voice: Night Elf sounds
- Placeholder racial faction name and description
- Model size and collision are the Troll model's
- Race ID above 64: `HelmetGeosetVisData` has no rows for it in a client without Retail support, so hair is not hidden under helmets there
