# mod-worgoblin-high-elf
## F-074_mod-playable-dracthyr-horde

### Features
- Playable Dracthyr (Horde), race ID 70 (retail's) set in config.sql
    - Retail model and full Retail customization in the wowdecomp-256-bit client (its `retailRaces` setting, default `52=52,70=70`), Dragon and Visage forms (Two Forms)
    - Everything else sees the Orc model and customization rows (a client without Retail support shows a orc)
    - Home: Orc (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Orc (voice, emotes and names, copied at build time)
    - Helmet prefix 'Or'
- Generated by `tools/races/dracthyr_modpaks.py` (tentative, for testing)

### Requirements
- wowdecomp-256-bit client built with `WOWDECOMP_RETAIL_ASSETS=ON`, with the Dracthyr Retail files (local CASC, a `pack=` folder or the Blizzard CDN)
- azerothcore-wotlk-256-bit with the Retail look tables and opcodes (characters keep their full customization and both forms; `RetailLook.TwoFormsRaces`)
- Interface: race button and the HORDEDRACTHYR entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`; `RetailRace_CharacterCreate.lua` for the Retail options

### Known Issues
- Tentative: not tested in game yet
- No racial mount
- Placeholder race icon
- No in-world form toggle yet (Visage): the form chosen in the character creator stays
- Soar flies with the stock flight rules; no Skyriding
- Model size and collision are the Orc model's

### CoA Custom 1.9 racials
- Active: learned with the racial skill line
- From CoA race 58 (Dracthyr (Horde)), renumbered; blocks at the end of `[BASE,F-074]_spell.sql`, `_skilllineability.sql` and `_spellicon.sql`
    - Wing Buffet: Stuns up to $i enemies within $a1 yds for $d.
    - Soar: Escape the effects of any immobilization or movement speed reduction effect and become immune to them for $81001d.
    - Draconic Mind: Intellect increased by $s1%.
    - Scales of the Aspects: Reduces the damage taken by spells by $s1%.
