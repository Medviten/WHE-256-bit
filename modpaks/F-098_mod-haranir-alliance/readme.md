# mod-worgoblin-high-elf
## F-098_mod-playable-haranir-alliance

### Features
- Playable Haranir (Alliance), race ID 86 (retail's) set in config.sql
    - Retail model and full Retail customization in the wowdecomp-256-bit client (its `retailRaces` setting, default `37=37,52=52,70=70,86=86,91=91`)
    - Any other client shows the native model with Retail's textures baked by `tools/models/haranir_native_prep.py`: 20 skin colours, 16 (male) / 18 (female) faces (half of them with Growth face paint), 18 hair styles, 30 hair colours, and 21 facial styles (male: each beard, moustache and pair of sideburns) / 14 eyebrows (female)
    - Fixed there: blue eyes, no fur patterns, no body paint, no hair highlights, jewelry, spines and tusks; default ears and nose
    - Home: Night Elf (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Night Elf (names, and the voice lines retail lacks)
    - Helmet prefix 'Ni'
- Generated by `tools/races/haranir_modpaks.py` (tentative, for testing)
- Voice: Retail's emotes, error lines and combat sounds (`tools/races/retail_voices.py`; files in WHE-common `Sound/character`), the Kin race's where retail has none
- Druid forms: retail's Haranir cat, bear, travel, aquatic, moonkin and tree forms (`tools/races/haranir_druid_forms.py`; models in WHE-common `Creature/druid*haranir`, `Creature/tindralmoonkin`), in retail's five colours following hair colour; flight forms are the Home race's (retail has none for Haranir)
- Shaman totems: retail's Haranir totem models (`tools/races/retail_totems.py`, `dbc/[F-098]_retail_totems.sql`; not in TrinityCore's retail data yet, so chosen by name: `haranir_totem_*`, in WHE-common)

### Requirements
- The client assets in WHE-common (`custom/haranir`)
- For the Retail look: wowdecomp-256-bit client built with `WOWDECOMP_RETAIL_ASSETS=ON`, with the Haranir Retail files (a `pack=` folder from `RetailPackBuild <pack> 86 91`, a local CASC or the Blizzard CDN)
- azerothcore-wotlk-256-bit with the Retail look tables and opcodes (characters keep their full customization)
- Interface: race button and the ALLIANCEHARANIR entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`; `RetailRace_CharacterCreate.lua` for the Retail options

### Known Issues
- Tentative: not tested in game yet
- No racial abilities yet
- No racial mount
- Placeholder racial faction name and description
- Model size and collision are the Night Elf model's
- Race ID above 64: `HelmetGeosetVisData` has no rows for it in a client without Retail support, so hair is not hidden under helmets there
