# mod-worgoblin-high-elf
## F-124_mod-playable-jinyu

### Features
- Playable Jinyu (Alliance), race ID set in config.sql
    - CoA's model and textures from Ilusixn's CoA 1.9.9 release (CoA race 78), prepared by `tools/models/coa199_race_prep.py`
    - Customization: CoA's own CharSections, hair and facial hair rows for its race 78
    - Home: NightElf (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Draenei (voice, emotes and names, copied at build time)
    - Helmet prefix 'Dr'
    - Model size and display scale from CoA's CreatureModelData/CreatureDisplayInfo rows
- Generated by `tools/races/coa199_race_modpaks.py` (tentative, for testing)

### Requirements
- Client files from `tools/models/coa199_race_prep.py` (in WHE-common's `patch-A.MPQ`)
- Interface: race button and the JINYU entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`

### Credits
- Model and textures: Uncle Snowzo (SnowzoCraft). See `CREDITS.md` in Ilusixn's CoA 1.9.9 release, which must ship with them

### Known Issues
- Tentative: not tested in game yet
- No racial mount
- Placeholder race icon
- Barber shop styles have generic names
- Character creation camera is not tuned for the model's size

### CoA Custom 1.9 racials
- Active: learned with the racial skill line
- From CoA (Ilusixn's CoA 1.9.9 release, CoA race 78) (Jinyu), renumbered; blocks at the end of `[BASE,F-124]_spell.sql`, `_skilllineability.sql` and `_spellicon.sql`
    - Waterspeaker's Blessing: Heals the target for $o1 over $d.  The amount healed is increased by your attack power.
    - Riptide Escape: Escape the effects of any immobilization or movement speed reduction effect and become immune to them for $81001d.
    - Gift of the River: Underwater breath lasts $s1% longer than normal.
    - Cold Currents: Reduces the damage taken by Frost spells by $s1%.
