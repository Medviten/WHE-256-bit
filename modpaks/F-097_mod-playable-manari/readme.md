# mod-worgoblin-high-elf
## F-097_mod-playable-manari

### Features
- Playable Man'ari (Horde), race ID set in config.sql
    - Stock draenei model, with four skin colours from the Alpha-Worgen package; stock draenei hair and facial hair
    - Home: BloodElf (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Draenei (voice, emotes and names, copied at build time)
    - Helmet prefix 'Dr'
- Generated by `tools/races/alpha_race_modpaks.py` (tentative, for testing)

### Requirements
- Interface: a race button and the MANARI entries in `CharacterCreate.lua`, `GlueParent.lua` and `GlueStrings.lua`

### Known Issues
- Tentative: not tested in game yet
- No racial abilities yet
- No racial mount
- Placeholder race icon, racial faction name and description
- Barber shop styles have generic names
- Race ID above 64: `HelmetGeosetVisData` has no rows for it, so hair is not hidden under helmets
- Only the first skin colour has its own underwear textures; the others share them
