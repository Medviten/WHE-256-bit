# mod-worgoblin-high-elf
## F-116_mod-playable-lich

### Features
- Playable Liches (Horde), race ID set in config.sql
    - CoA's model and textures from Ilusixn's CoA 1.9.9 release (CoA race 122), prepared by `tools/models/coa199_race_prep.py`
    - Customization: the 7/7 skin colours of CoA's appearance catalog (`EsteriaLich.bin`); its other options (EsteriaAppearance.dll) are fixed at their first choice
    - Home: Undead (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Undead (voice, emotes and names, copied at build time)
    - Helmet prefix 'Gn'
    - Model size and display scale from CoA's CreatureModelData/CreatureDisplayInfo rows
- Generated by `tools/races/coa199_race_modpaks.py` (tentative, for testing)

### Requirements
- Client files from `tools/models/coa199_race_prep.py` (in WHE-common's `patch-A.MPQ`)
- Custom client with `creatureSkinRaces` containing the race ID: the skin texture is composited whole and armour textures are not drawn on it
- Interface: race button and the LICH entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`

### Credits
- Model and textures: the AllRaces v12 pack: Furioz, Corruption, Eunoia, Kalibros (STRHercules). See `CREDITS.md` in Ilusixn's CoA 1.9.9 release, which must ship with them

### Known Issues
- Tentative: not tested in game yet
- No racial mount
- Placeholder race icon
- Barber shop styles have generic names
- Character creation camera is not tuned for the model's size
- CoA's extra appearance options (EsteriaAppearance.dll) are not available

### CoA Custom 1.9 racials
- Active: learned with the racial skill line
- From CoA (Ilusixn's CoA 1.9.9 release, v12 racials of CoA race 122) (Lich), renumbered; blocks at the end of `[BASE,F-116]_spell.sql`, `_skilllineability.sql` and `_spellicon.sql`
    - Necrotic Aura: The grave already took what it wanted. Reduces Shadow and Frost damage taken by 3%.
    - Arcane Scholar: Death sharpened the mind. Intellect increased by 5%.
    - Deathless Resolve: The phylactery keeps you standing. Total health increased by 5%.
    - Necrotic Ward: Wrap yourself in grave-cold energy, absorbing magic damage for 5 sec. 1 minute cooldown.
