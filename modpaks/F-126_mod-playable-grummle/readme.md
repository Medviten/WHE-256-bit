# mod-worgoblin-high-elf
## F-126_mod-playable-grummle

### Features
- Playable Grummles (Alliance), race ID set in config.sql, one body for both genders
    - CoA's model and textures from Ilusixn's CoA 1.9.9 release (CoA race 103), prepared by `tools/models/coa199_race_prep.py`
    - Customization: CoA's own CharSections, hair and facial hair rows for its race 103
    - Home: Dwarf (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Gnome (voice, emotes and names, copied at build time)
    - Helmet prefix 'Gn'
    - Model size and display scale from CoA's CreatureModelData/CreatureDisplayInfo rows
- Generated by `tools/races/coa199_race_modpaks.py` (tentative, for testing)

### Requirements
- Client files from `tools/models/coa199_race_prep.py` (in WHE-common's `patch-A.MPQ`)
- Interface: race button and the GRUMMLE entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`

### Credits
- Model and textures: the Grummle model from Ascension / retail assets, converted for WotLK. See `CREDITS.md` in Ilusixn's CoA 1.9.9 release, which must ship with them

### Known Issues
- Tentative: not tested in game yet
- No racial mount
- Placeholder race icon
- Barber shop styles have generic names
- Character creation camera is not tuned for the model's size
- One body: both genders use it, with the Kin race's voices

- From CoA (Ilusixn's CoA 1.9.9 release, CoA race 103) (Grummle), renumbered; blocks at the end of `[BASE,F-126]_spell.sql`, `_skilllineability.sql` and `_spellicon.sql`
    - Pack Toss: Stuns up to $i enemies within $a1 yds for $d.
    - Trail Snack: When activated, regenerates $20578s1% of total health every $20578t1 sec for $20578d.  Only works on Humanoid or Undead corpses within $a1 yds.  Any movement, action, or damage taken while Cannibalizing will cancel the effect.
    - Lucky Foot: Increases your dodge chance by $s1%.
    - Heavy Pack: Base Health increased by $s1%.
