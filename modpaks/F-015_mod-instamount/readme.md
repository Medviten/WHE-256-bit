# mod-worgoblin-high-elf
## F-015_mod-instamount

### Features
- Instacast mount spells
    - Any spell that applies the mounted aura becomes instant 
    - Can also be cast while moving
    - Mount-like spells (e.g. Ghost Wolf, Running Wild) are also instant
- Mounts usable indoors
- Dynamic riding speed
    - Journeyman Riding (Riding skill 150) grants a hidden passive that makes every mount at least 100% speed
