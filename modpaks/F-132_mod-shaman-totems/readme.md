# mod-worgoblin-high-elf
## F-132_mod-shaman-totems

### Features
- Gives stock races another race's shaman totems (the totem counterpart of F-011_mod-druid-forms)
    - Gnome: Goblin totems (from F-023_mod-playable-goblin)

### Known Issues
- None

### Considerations
- Off by default. Looks only: the totems behave as usual.
- A set is only used when the modpak that brings it is installed (its totem models are in the DBCs); otherwise the race
  keeps its totems, or F-026's Alliance/Horde default.
- Run it after the race modpaks it takes totems from (as in the manifest).
- Needs those totems' client models (patch-A).
