# mod-worgoblin-high-elf
## F-125_mod-playable-two-headed-ogre

### Features
- Playable Two-Headed Ogres (Horde), race ID set in config.sql, one body for both genders
    - CoA's model and textures from Ilusixn's CoA 1.9.9 release (CoA race 85), prepared by `tools/models/coa199_race_prep.py`
    - Customization: CoA's own CharSections, hair and facial hair rows for its race 85
    - Home: Orc (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Orc (voice, emotes and names, copied at build time)
    - Helmet prefix 'Or'
    - Model size and display scale from CoA's CreatureModelData/CreatureDisplayInfo rows
- Generated by `tools/races/coa199_race_modpaks.py` (tentative, for testing)

### Requirements
- Client files from `tools/models/coa199_race_prep.py` (in WHE-common's `patch-A.MPQ`)
- Interface: race button and the TWOHEADEDOGRE entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`

### Credits
- Model and textures: Stefan (stefanw1337): Two-Headed Ogre. See `CREDITS.md` in Ilusixn's CoA 1.9.9 release, which must ship with them

### Known Issues
- Tentative: not tested in game yet
- No racial mount
- Placeholder race icon
- Barber shop styles have generic names
- Character creation camera is not tuned for the model's size
- One body: both genders use it, with the Kin race's voices

### CoA Custom 1.9 racials
- Active: learned with the racial skill line
- From CoA race 53 (Ogre (CoA's Two-Headed Ogre has none of its own)), renumbered; blocks at the end of `[BASE,F-125]_spell.sql`, `_skilllineability.sql` and `_spellicon.sql`
    - Ogre Slam: Stuns up to $i enemies within $a1 yds for $d.
    - Two Heads Are Better: Base Health increased by $s1%.
    - Thick Skull: Duration of Stun effects reduced by an additional $s1%.
    - Club Mastery: Expertise with with Maces and Two-Handed Maces increased by $s1.
