# mod-worgoblin-high-elf
## F-052_mod-playable-qiraji

### Features
- Playable Qiraji (Horde), race ID set in config.sql
    - WallCraft's playable Qiraji model (Vanilla format, converted with m2_256_to_264.py) and its donor customization rows
    - Home: Orc (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Orc (voice, emotes and names, copied at build time)
    - Helmet prefix 'Ni'
- Generated by `tools/races/new_race_modpaks.py` (tentative, for testing)

### Requirements
- Interface: a race button and the QIRAJI entries in `CharacterCreate.lua`, `GlueParent.lua` and `GlueStrings.lua`

### Known Issues
- Tentative: not tested in game yet
- No racial abilities yet
- No racial mount
- Placeholder race icon, racial faction name and description
- Barber shop styles have generic names
- Character creation camera is not tuned for the model's size
- Converted Vanilla model: armour may composite oddly (try adding the race to `creatureSkinRaces`)
