# mod-worgoblin-high-elf
## F-117_mod-playable-mogu

### Features
- Playable Mogu (Alliance), race ID set in config.sql
    - CoA's model and textures from Ilusixn's CoA 1.9.9 release (CoA race 123), prepared by `tools/models/coa199_race_prep.py`
    - Customization: the 12/12 skin colours of CoA's appearance catalog (`EsteriaMogu.bin`); its other options (EsteriaAppearance.dll) are fixed at their first choice
    - Home: Human (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Human (voice, emotes and names, copied at build time)
    - Helmet prefix 'Gn'
    - Model size and display scale from CoA's CreatureModelData/CreatureDisplayInfo rows
- Generated by `tools/races/coa199_race_modpaks.py` (tentative, for testing)

### Requirements
- Client files from `tools/models/coa199_race_prep.py` (in WHE-common's `patch-A.MPQ`)
- Custom client with `creatureSkinRaces` containing the race ID: the skin texture is composited whole and armour textures are not drawn on it
- Interface: race button and the MOGU entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`

### Credits
- Model and textures: the AllRaces v12 pack: Furioz, Corruption, Eunoia, Kalibros (STRHercules). See `CREDITS.md` in Ilusixn's CoA 1.9.9 release, which must ship with them

### Known Issues
- Tentative: not tested in game yet
- No racial mount
- Placeholder race icon
- Barber shop styles have generic names
- Character creation camera is not tuned for the model's size
- CoA's extra appearance options (EsteriaAppearance.dll) are not available

### CoA Custom 1.9 racials
- Active: learned with the racial skill line
- From CoA (Ilusixn's CoA 1.9.9 release, v12 racials of CoA race 123) (Mogu), renumbered; blocks at the end of `[BASE,F-117]_spell.sql`, `_skilllineability.sql` and `_spellicon.sql`
    - Stoneskin: Mogu skin is carved, not grown. Reduces Physical damage taken by 3%.
    - Thunder King's Might: The old thunder kings ruled by strength. Strength increased by 5%.
    - Pride of the Mogu: An empire's pride keeps you on your feet. Total health increased by 5%.
    - Stonebreaker Shockwave: Slam the ground and send a stone shockwave in front of you, damaging and stunning all enemies in a cone. 1 minute cooldown.
