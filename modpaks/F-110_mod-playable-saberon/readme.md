# mod-worgoblin-high-elf
## F-110_mod-playable-saberon

### Features
- Playable Saberon (Alliance), race ID set in config.sql, one body for both genders
    - CoA's model and textures from Ilusixn's CoA 1.9.9 release (CoA race 97), prepared by `tools/models/coa199_race_prep.py`
    - Customization: the 4/4 skin colours of CoA's appearance catalog (`EsteriaSaberon.bin`); its other options (EsteriaAppearance.dll) are fixed at their first choice
    - Home: NightElf (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: NightElf (voice, emotes and names, copied at build time)
    - Helmet prefix 'Ta'
    - Model size and display scale from CoA's CreatureModelData/CreatureDisplayInfo rows
- Generated by `tools/races/coa199_race_modpaks.py` (tentative, for testing)

### Requirements
- Client files from `tools/models/coa199_race_prep.py` (in WHE-common's `patch-A.MPQ`)
- Custom client with `creatureSkinRaces` containing the race ID: the skin texture is composited whole and armour textures are not drawn on it
- Interface: race button and the SABERON entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`

### Credits
- Model and textures: Project Ascension's model, in Ilusixn's CoA Custom release. See `CREDITS.md` in Ilusixn's CoA 1.9.9 release, which must ship with them

### Known Issues
- Tentative: not tested in game yet
- No racial mount
- Placeholder race icon
- Barber shop styles have generic names
- Character creation camera is not tuned for the model's size
- CoA's extra appearance options (EsteriaAppearance.dll) are not available
- The DLL's baked armour (geosets 200xx, drawn with its texture type 14) is hidden
- One body: both genders use it, with the Kin race's voices

### CoA Custom 1.9 racials
- Active: learned with the racial skill line
- From CoA (Ilusixn's CoA 1.9.9 release, CoA race 97) (Saberon), renumbered; blocks at the end of `[BASE,F-110]_spell.sql`, `_skilllineability.sql` and `_spellicon.sql`
    - Pounce: Stuns up to $i enemies within $a1 yds for $d.
    - Feline Grace: Increases your dodge chance by $s1%.
    - Predator: Damage dealt versus Beasts increased by $s1%.
    - Shadow Prowl: Reduces the chance enemies have to detect you while Shadowmelded or Stealthed.
