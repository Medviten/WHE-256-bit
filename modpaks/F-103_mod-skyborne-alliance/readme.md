# mod-worgoblin-high-elf
## F-103_mod-skyborne-alliance

### Features
- Playable Skyborne (Alliance), race ID 95 (Forever's) set in config.sql
    - Forever model and full Forever customization in the wowdecomp-256-bit client (its `retailRaces` setting, default `...,95=forever:95,96=forever:96`), when `Data/Retail/ForeverCasc.ini` is installed
    - Any other client (and the Retail client without Forever data) shows the native model from Kalibro's races package: 5 skin colours x 26 eye colours, 10 faces, 25 (male) / 29 (female) hair styles each with or without feathers, 32 hair colours, and beard x eyebrows (male) / eyebrows (female) as facial styles
    - Home: Human (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Blood Elf (names, and the voice lines Forever lacks)
    - Helmet prefix 'Be'
- Generated by `tools/races/skyborne_modpaks.py` (tentative, for testing)
- Voice: Forever's emotes, error lines and combat sounds (`tools/races/retail_voices.py`; files in WHE-common `Sound/character`), the Kin race's where Forever has none

### Requirements
- The client assets in WHE-common (`custom/skyborne`)
- For the Forever look: wowdecomp-256-bit client built with `WOWDECOMP_RETAIL_ASSETS=ON`, with `config/ForeverCasc.example.ini` copied to `Data/Retail/ForeverCasc.ini` and the Skyborne Forever files (`RetailPackBuild --forever Data/Retail/ForeverPack 95 96`, or the Blizzard CDN)
- azerothcore-wotlk-256-bit with the Retail look tables and opcodes (characters keep their full customization)
- Interface: race button and the ALLIANCESKYBORNE entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`; `RetailRace_CharacterCreate.lua` for the Forever options

### Known Issues
- Tentative: not tested in game yet
- No racial abilities yet
- No racial mount
- Placeholder racial faction name and description
- Native look: one feather colour (Seafoam), Long ears, no horns, blindfolds, tattoos or jewelry, and only 26 of the 47 eye colours (Kalibro's bake); the 130 skin colours make that slider long
- Race ID above 64: `HelmetGeosetVisData` has no rows for it in a client without Retail support, so hair is not hidden under helmets there
